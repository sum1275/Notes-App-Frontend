# Notes Application (MERN Stack)

A full-stack Notes Application built using the MERN stack (MongoDB, Express.js, React.js, Node.js). It allows users to manage their notes with CRUD functionality and secure authentication.

## Features
- **CRUD Operations**: Create, Read, Update, and Delete notes.
- **Category Filtering**: Filter notes by category.
- **User Authentication**: JWT-based authentication with secure password hashing.
- **Responsive UI**: Built with React.js, React Router, and Tailwind CSS.
- **Security**: Routes secured with JWT middleware and Helmet.js for HTTP headers.
